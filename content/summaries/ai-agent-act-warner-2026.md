# AI AGENT Act (Warner, 2026) — Discussion Draft

## Document Details

- **Sponsor:** Senator Mark Warner (D-VA)
- **Type:** Discussion draft (legislation)
- **Date:** June 29, 2026
- **URL:** https://www.warner.senate.gov/wp-content/uploads/2026/06/DRAFT.AI_AGENT_Act_onepager.v2.pdf

## Summary

The **AI AGENT Act** is the first piece of federal legislation specifically targeting AI agents as a distinct category. Proposed by Senator Mark Warner, the discussion draft proposes a framework that treats certain AI agents — specifically "custodial user agents" that access sensitive consumer data — as fiduciary-like entities with legal obligations to serve consumer interests.

## Key Provisions

### 1. FTC Registry of Trusted AI Agents
- Requires AI agents that perform consumer-facing actions to register with the FTC
- Provides transparency for consumers about which AI systems they interact with
- Creates a formal mechanism for tracking AI agent deployment

### 2. Fiduciary-Like Duties for Custodial User Agents
- "Custodial user agents" (those accessing email, e-commerce, credit cards, or other sensitive personal data) would be subject to fiduciary-like duties
- These duties require the agent to prioritize the consumer's interests above all others
- Analogous to the fiduciary duties owed by financial advisors, lawyers, and doctors to their clients

### 3. Prohibition on Secondary Commercial Use of User Data
- Prohibits repurposing user data collected by AI agents for secondary commercial use
- Prevents AI agents from serving as vectors for data exploitation
- Addresses one of the core concerns identified in the Ada Lovelace Institute's Delegation Nation briefing

### 4. NIST-Developed Agent Authentication Standards
- Requires NIST to develop technical standards for authenticating AI agents
- Enables consumers to verify the identity and trustworthiness of AI agents
- Complements the FTC's accuracy framework by providing a technical authentication layer

## Relevance to UK Consumer Harms

This is a **landmark policy development** that directly addresses the institutional design challenges identified in Hadfield & Koh (2025) and the Ada Lovelace Institute's research:

1. **Fiduciary duty concept:** The AI AGENT Act's fiduciary-duty framework for custodial agents directly addresses the conflict-of-interest problem documented by Wu et al. (2026). If an AI agent has a fiduciary duty to the consumer, it cannot simultaneously serve a company's sponsored-content interests.

2. **Institutional redesign in practice:** This is a concrete example of the institutional redesign that Hadfield & Koh argued was necessary for AI agents as non-human economic actors. The FTC registry creates agent identity/registration; fiduciary duties create a regulatory framework; NIST authentication addresses the corporate boundary problem.

3. **Data protection:** The prohibition on secondary commercial use directly addresses the privacy concerns identified in Delegation Nation and the [[agentic-commerce-tokenization]] concept.

4. **UK policy relevance:** The UK's sector-led regulatory approach (DMCC Act 2024) could adapt similar fiduciary-duty concepts for high-risk AI agents operating in UK markets.
