## Overview

Existing travel planning agents rely on hand-crafted prompts and fixed workflows, limiting flexibility. DeepTravel enables autonomous planning, tool execution, and reflection on tool responses.

## Key Contributions

1. **End-to-End RL Framework**: Autonomous travel planning agent with tool usage and reflection
2. **Travel Sandbox**: Cached transportation, accommodation, and POI data for training
3. **Hierarchical Reward Modeling**:
   - Trajectory-level verifier: spatiotemporal feasibility
   - Turn-level verifier: itinerary-detail consistency
4. **Reply-Augmented RL**: Periodically replays from failure experience buffer
5. **Production Deployment**: Live in DiDi Enterprise Solutions for 3 months

## Performance

- **82% accuracy** in travel itinerary generation (3-month online test)
- **Small LLM advantage**: Qwen3-32B outperforms OpenAI o1/o3 and DeepSeek-R1
- Significantly outperforms existing TP agent frameworks

## Architecture

```
Agent → Planning → Tool Execution → Response Analysis
                                    ↓
               Hierarchical Reward (Trajectory + Turn Level)
                                    ↓
               Reply-Augmented RL → Failure Buffer Replay
```

## Implications for Consumer Protection

- **Autonomous Decision-Making**: RL-optimized travel planning may prioritize business objectives over consumer welfare
- **Proprietary Advantage**: Small models outperforming frontier models could concentrate power among well-funded enterprises
- **Deployment Scale**: Production deployment in DiDi's enterprise platform reaches millions of users
- **Reward Manipulation**: RL agents optimize for defined rewards, which may not align with consumer interests
- **Transparency**: Consumers unaware that travel itineraries are generated by RL agents optimizing for specific metrics
- **Accountability Gaps**: When autonomous agents make errors, difficulty determining responsibility
