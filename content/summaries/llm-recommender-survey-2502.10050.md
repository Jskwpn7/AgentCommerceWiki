## Overview

This survey provides systematic review of LLM-powered agents transforming recommender systems, from traditional collaborative filtering to agentic, conversational interfaces.

## Three Key Paradigms

### 1. Recommender-Oriented Approaches
- Intelligent agents enhance fundamental recommendation mechanisms
- LLMs improve item representation, ranking, and personalization

### 2. Interaction-Oriented Approaches
- Dynamic user engagement through natural dialogue
- Interpretable suggestions with explanations

### 3. Simulation-Oriented Approaches
- Multi-agent frameworks model complex user-item interactions
- System dynamics simulation for evaluation

## Architectural Components

Analysis of essential LLM-powered recommendation agent components:
1. **Profile Construction**: Building user representations
2. **Memory Management**: Storing and retrieving interaction history
3. **Strategic Planning**: Deciding recommendation strategies
4. **Action Execution**: Delivering recommendations through appropriate channels

## Key Findings

- LLM-powered agents enable natural language interaction with recommenders
- Memory management is critical for long-term personalization
- Multi-agent simulation enables safer evaluation of recommendation strategies
- Benchmark datasets and evaluation frameworks still evolving

## Implications for Consumer Protection

- **Explainability**: LLM agents can explain recommendations in natural language, improving transparency
- **Manipulation Risk**: Natural conversation may make users more susceptible to recommendation manipulation
- **Privacy**: Profile construction and memory management require extensive user data
- **Evaluation Gap**: Current benchmarks may not capture long-term consumer harm
