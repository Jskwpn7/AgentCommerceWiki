# Micro-Transaction Markets for Verified Information in Agentic Commerce

## Overview

A proposed economic model for agentic e-commerce where buyer agents spend fractions of a cent to unlock verified seller information (product histories, test reports, BOMs, audited metrics). Introduced as a vision paper by Ventirozos & Shardlow (2026).

## Mechanism

1. **Seller uploads verified data** (test reports, BOMs, sales metrics) to a verification layer
2. **Buyer agents query the data** by paying sub-cent micropayments via protocols like x402 or Google AP2
3. **Freemium model:** Basic product info is free; verified data costs fractions of a cent per query
4. **Trust scoring:** Reviewer trust scored reputationally by agents

## Consumer Harm Risks

- **Pay-to-know information asymmetry:** Verified information gated behind micropayments disadvantages price-sensitive consumers
- **Machine-speed extraction:** Sub-cent payments at machine speed enable data extraction without human consent
- **Affiliate manipulation:** Sellers can buy better discoverability from buyer agents at scale
- **Trust score manipulation:** Freemium reputation scoring creates new vectors for review manipulation
